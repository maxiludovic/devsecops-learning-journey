# 📜 Bash-Skripte

Meine Bash-Übungen, vom ersten Skript bis zur Automatisierung.

| Skript | Thema |
|---|---|
| `bash-basics/variables.sh` | Variablen, Kommando-Substitution `$(date)`, Skript-Argumente `$1` und `$#` |
| `bash-basics/boucles.sh` | Schleifen: `for` mit Liste und Bereich `{1..5}`, `while` mit Zähler, Schleife über Dateien |

**Ausführen** (Linux / WSL2):
```bash
chmod +x scripts/bash-basics/*.sh
./scripts/bash-basics/variables.sh Hallo Welt
./scripts/bash-basics/boucles.sh
```
